# PR7 — Barre latérale, sortie de caisse, client en caisse, logo

**Demande (15/09/2026) :** reprendre la barre latérale de l'application
source (Frip & Co Street en est un calque simplifié), ajouter des boutons
de sortie de la caisse, gérer le client en caisse même s'il ne cumule
rien, corriger l'apparence du logo. Sans fidélité, sans points, sans
catalogue. Le nom de l'application source ne doit apparaître nulle part
(test d'isolation).

## 2. Hors périmètre
Points, carte, bons, avoir, SMS, rôles multiples, historique d'achats détaillé en caisse (au-delà de « N visites, dernière le … »).

## 3. Tests attendus
- Migration 0007 réversible sur base vierge et sur une base contenant des clients avec e-mail.
- Service : recherche par e-mail, nom, téléphone (avec espaces et `+33`) ; création sans e-mail ; création idempotente (même e-mail → même fiche, `created=false`) ; `contact_required` ; anonymisation efface le téléphone ; `sync_brevo` ignoré sans e-mail.
- Routes : 401 sans JWT ; vente avec `client_id` → transaction liée, hash identique à une vente sans client (mêmes montants) ; `DELETE …/client` détache ; JET `client.linked` sans PII ; ticket texte contient « Client : Prénom N. » et jamais l'e-mail ni le téléphone.
- Front : lint, tsc, build ; parcours Playwright contre la pile réelle (validateur) : sidebar réduite/étendue persistée, hamburger mobile, entrées `?tab=` ouvrant le bon onglet, déconnexion depuis la caisse et depuis la barre, sélection puis création d'un client en caisse, vente liée, nom sur le ticket, détachement.
- Isolation : `tests/test_isolation.py` vert ; aucune mention du nom de l'application source dans le code, les docs ou les commentaires.
